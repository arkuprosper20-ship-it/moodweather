Alerts describe patterns across groups. They never point to individual students.

Patterns, not diagnoses

MoodWeather shows trends across groups over time. It never diagnoses a condition or labels a student.

Never identify individuals

Don't try to work out who is behind a check-in. Groups with fewer than 5 responses are hidden for exactly this reason.

Refer concerns to the counselor

If a pattern worries you, flag it to the school counselor. They're trained to follow up safely and privately.

Start conversations, not labels

Use the data to ask “how are we doing as a grade?” — never to single out a student or a class.

What students see

A private daily check-in: anonymous, no names, no accounts, one check-in per day.

What you see: group patterns only. No student names or individual responses are stored or shown anywhere in MoodWeather.

MoodWeather needs a web server.

ES modules cannot load from file://. Serve this folder over HTTP — for example python -m http.server or npx serve — or use VS Code's Live Server extension, then open the page.
